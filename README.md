# Dashboard-business-insights
Power BI dashboard built using a Kaggle fashion e-commerce dataset. Performed feature selection, data cleaning, and analysis to uncover insights on customer preferences, product engagement, pricing trends, discounts, and category performance, enabling data-driven business decisions.
📊 Product Performance & Customer Insights Dashboard
Overview

This project analyzes a fashion e-commerce dataset from Kaggle using Power BI to understand customer behavior, product performance, pricing strategies, and category trends.

Rather than using all available fields, a feature selection process was performed to retain only the most relevant attributes for business analysis, improving dashboard clarity and insight generation.

Objectives
Understand customer preferences across product categories.
Identify products driving the highest engagement.
Analyze the impact of discounts on customer ratings.
Discover premium product categories based on pricing.
Generate actionable business insights through visualization.

Key Findings
Highly rated categories indicate strong customer satisfaction.
Product inventory is concentrated within a few major categories.
Discounts alone do not guarantee higher ratings.
A small number of products generate significant customer engagement.
Premium categories present opportunities for higher-margin growth.
